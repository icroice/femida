# 012 — Модуль `release`

## Цель

Замыкающая стадия: версии проекта и релизные срезы.

## Контекст

Спека §3. Задача проходит `qa` (011) и попадает в релизную стадию.

## Критерии готовности

- Дескриптор модуля: секция релизов, роли, колонка «Релиз».
- Версии проекта: создание, список задач среза (что вошло).
- Задача в колонке «Релиз» закрывается вместе со срезом (история 005).
- Сводка среза: список задач с итоговыми статусами QA (markdown, как
  QA-сводки v1).
- Права через AccessService.

## Нерешённые вопросы

- Семантика версий (semver?) и теги.
- Черновик релиза против «выпущено» — нужны ли оба состояния.
