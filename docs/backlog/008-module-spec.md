# 008 — Модуль `spec`

## Цель

Стадия проработки: требования и критерии готовности в задаче.

## Контекст

Спека §3. Задача приходит из `backlog` (007), уходит в `dev` (009).

## Критерии готовности

- Дескриптор модуля: секция проработки, роли, колонка «Проработка».
- В задаче появляется блок «Требования» (markdown) и «Критерии готовности»
  (чек-лист с отметками).
- Права: редактировать проработку может роль модуля, видеть — участники.
- Перевод в разработку требует непустых критериев готовности.
- Вердикт «спека готова» фиксируется в истории задачи (005).

## Нерешённые вопросы

- Шаблоны проработки (пресеты критериев) — нужны ли сразу.
