# 019 — Комментарии в задачах

## Цель

Обсуждение под задачей: комментарий участника, отметки, лёгкая разметка.

## Контекст

Решение v2-9. Замечания ревью — отдельный механизм модуля `review` (010),
комментарии — общие для всей жизни задачи.

## Критерии готовности

- Модель и миграция; автор, текст (markdown), время; правка своего
  комментария в окне (например 15 минут), удаление — своё.
- UI: лента под карточкой задачи, форма внизу, аватары авторов.
- Запись через REST v2 (017) — агенты комментируют от имени ключа проекта.
- Событие комментария — кандидат в уведомления (020): упоминания `@user`.

## Нерешённые вопросы

- Вложения-картинки в комментарии — v2.0 или потом.
