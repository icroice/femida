# 002 — Канбан-доска проекта

## Цель

Доска как главный экран проекта: колонки приходят из включённых
модулей-стадий, карта задачи, перенос между колонками с историей.

## Контекст

Спека §6. Стадии стартового набора: backlog → spec → dev → review → qa →
release. Зависит от 001 (дескрипторы объявляют колонки).

## Критерии готовности

- Колонки доски — декларации включённых модулей, порядок по жизненному циклу.
- Перенос карты фиксируется историей задачи (кто, когда, куда).
- Фильтры по исполнителю и модулю; счётчики в колонках.
- Доступность колонок и действий — через AccessService.
- Пустые состояния и мобильный вид — по стайлгайду.

## Нерешённые вопросы

- Нужен ли WIP-лимит (пока не вводим).
- Drag-and-drop или кнопки-переходы на мобильных.
