# 025 — Пользователи: создание и удаление

## Цель

Страница `/users` умеет создавать и удалять пользователей (ТЗ §7).

## Контекст

Сейчас на `/users` только просмотр (v1). Управление — системный админ;
флаг `is_admin` задаётся при создании.

## Критерии готовности

- Создание: имя, email, пароль, флаг админа; валидация как у v1-форм.
- Удаление по правилу ТЗ §10.3 (рекомендация: запрет, пока пользователь
  назначен исполнителем или имеет ключи; в сообщении — причина).
- Страница и действия — только системный админ (через AccessService).
- Тесты: создание, удаление, запрет при зависимостях, доступ.

## Нерешённые вопросы

- Правило удаления (ТЗ §10.3) — подтвердить при взятии задачи.
