# 017 — REST v2: запись для агентов и интеграций

## Цель

Публичный REST v2 для задач: создание, редактирование, переходы между
стадиями, комментарии. Машинная запись — здесь, MCP остаётся чтением
(решение v2-12).

## Контекст

Паттерн v1: агент читает через MCP, грузит через REST. Ключи проектов —
тот же вход, префикс версий: `/api/v2/...`.

## Критерии готовности

- Ресурсы: задачи (CRUD), переход (`POST /tasks/{id}/move`), комментарии.
- Валидация и ошибки — единый формат с v1 (json-структура ответов).
- Доступ: ключ проекта ∧ модуль включён ∧ право роли (AccessService).
- Переходы через API пишут ту же историю, что UI (005).
- OpenAPI-описание или эквивалентная документация в docs/.
- Тесты контракта: happy path + ошибки доступа + выключенный модуль.

## Нерешённые вопросы

- Пагинация/фильтры списков — сразу или по мере надобности.
- Идемпотентность создания (external id у источника?).
