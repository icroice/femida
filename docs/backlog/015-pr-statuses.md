# 015 — Статусы pull request с git-хостинга

## Цель

Карточка задачи в стадии `dev` показывает живой статус PR: открыт / слит /
закрыт.

## Контекст

Решение v2-9: единственная интеграция в v2.0. Поля «ветка» и «PR» — задача
009. Femida — хаб без доступа к репозиториям: статусы тянут по ссылке,
ничего не клонируется.

## Критерии готовности

- Настройка на проект: хостинг-тип (github/gitea/forgejo…) и токен
  (или безтокенный публичный доступ).
- Опрос статуса по расписанию/при открытии доски; результат кэшируется
  с таймстемпом.
- Статус виден на карточке и в блоке `dev` задачи; слитый PR подсвечивает
  готовность к переходу в `review`.
- Ошибки доступа к хостингу — тихая деградация с пометкой «статус неизвестен».

## Нерешённые вопросы

- Webhook вместо опроса — или опроса достаточно для v2.0.
- Какие хостинги в первом срезе (рекомендация: github + gitea-совместимые).
