# 018 — MCP-инструменты задач (чтение)

## Цель

Агент видит трекер через MCP: задачи проекта, карточка, критерии готовности,
статусы стадий. Read-only (запись — REST v2, задача 017).

## Контекст

Решения v2-9, v2-12. Агрегатор 013 уже собирает декларации; инструменты
задач декларирует ядро.

## Критерии готовности

- Инструменты: список задач (фильтры стадия/исполнитель), карточка задачи,
  критерии готовности, история переходов.
- Набор инструментов зависит от включённых модулей проекта (кто ключ).
- Ответы — тот же формат, что у v1-инструментов (консистентность клиента).
- Документация инструментов в docs/skill.md обновлена под v2.
- Тесты: набор меняется при включении/выключении модулей.

## Нерешённые вопросы

- Гранулярность: один инструмент-«задачи» с параметрами против отдельных
  на каждый срез.
