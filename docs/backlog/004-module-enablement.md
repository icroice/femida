# 004 — Включение модулей и их жизненный цикл

## Цель

Два шага включения модуля, UI обоих шагов, спящие роли, жизненный цикл
модуля при удалении.

## Контекст

Спека §5. Движок и таблицы — 001. Карточки-тумблеры и lock-бейджи —
паттерны стайлгайда.

## Критерии готовности

- Админ инстанса предоставляет модули проектам (UI: реестр модулей ×
  проекты).
- Владелец проекта включает предоставленные модули (UI: карточки с
  тумблером; непредоставленные — приглушены lock-бейджем, не спрятаны).
- Роль модуля, которого лишили предоставления, спит: членство легально,
  UI/API модуля скрыты; при возврате модуля роль оживает.
- Назначить спящую роль нельзя: фильтр ролей по предоставленным модулям
  работает везде, где роли выбирают.
- Релиз, убирающий модуль или роль, несёт миграцию, гасящую их строки в БД.
- Неизвестная роль (модуль исчез) отображается слагом, не 500.

## Нерешённые вопросы

- Журнал предоставлений/включений (кто и когда) — нужен ли.
