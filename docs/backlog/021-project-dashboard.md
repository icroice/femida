# 021 — Дашборд проекта

## Цель

Сводный экран проекта: распределение задач по стадиям, активность,
последние события.

## Контекст

Решение v2-9. Первый экран после входа в проект (сейчас — доска).
Данные уже есть: задачи, история переходов, уведомления (020).

## Критерии готовности

- Плитки-счётчики по стадиям (открыто/в работе/готово) с переходом в доску
  с фильтром.
- Активность: последние переходы и комментарии проекта (кто, что, когда).
- Блок QA: последние прогоны и вердикты (данные модуля `qa`, если включён).
- Пустой проект: приглашение создать задачи (пустое состояние по стайлгайду).
- Обновление — обычной перезагрузкой, без вебсокетов.

## Нерешённые вопросы

- Период «активности» (неделя?) и глубина ленты.
