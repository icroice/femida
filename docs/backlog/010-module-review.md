# 010 — Модуль `review`

## Цель

Стадия ревью кода: замечания и статусы цикла.

## Контекст

Спека §3. Задача приходит из `dev` (009), уходит в `qa` (011).

## Критерии готовности

- Дескриптор модуля: секция ревью, роли, колонка «Ревью».
- Замечания ревьюера — списком в задаче (текст + автор + статус:
  открыто/исправлено/отклонено).
- Цикл: «на ревью» → «правки» (возврат в `dev`) → «одобрено» → в `qa`.
- Каждое решение фиксируется в истории задачи.
- Права через AccessService; ревьюер и автор — разные люди не требуются
  (само-ревью разрешено, помечается).

## Нерешённые вопросы

- Требовать ли второго ревьюера для релиз-критичных задач.
