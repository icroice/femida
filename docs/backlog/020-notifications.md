# 020 — Уведомления

## Цель

Внутренний инбокс: колокольчик из каркаса (006), непрочитанные события,
страница-лента.

## Контекст

Решение v2-9. Источники событий: переходы задач (005), назначения
исполнителя, комментарии с упоминанием (019), вердикты QA.

## Критерии готовности

- Модель событий уведомлений: адресат, тип, ссылка на задачу, прочитано.
- Правила адресации: исполнитель задачи, автор комментария при ответе,
  упомянутый `@user`, владелец проекта при блокировке.
- Колокольчик: счётчик непрочитанных, дропдаун последних, «все» — страница.
- Прочитано: по клику/открытию; массовое «прочитать всё».
- Email не шлём (self-hosted, без внешних зависимостей) — только инбокс.

## Нерешённые вопросы

- Дайджест против потока на странице ленты.
- Уровень шума: группировка повторных событий одной задачи.
