# 013 — MCP-агрегатор модулей

## Цель

MCP-сервер собирает инструменты из деклараций включённых модулей проекта,
а не из жёсткого списка.

## Контекст

Спека §7. После 011 инструменты v1 уже декларированы модулем `qa`;
здесь агрегатор становится общим механизмом.

## Критерии готовности

- Дескриптор модуля декларирует MCP-инструменты (имена, схемы, обработчики).
- Сервер отдаёт клиенту только инструменты включённых модулей проекта,
  чей ключ предъявлен.
- Вызов инструмента выключенного модуля — внятная ошибка, не 500.
- Контракты v1-инструментов не меняются (существующие клиенты работают).
- Тесты агрегатора: набор инструментов меняется при включении/выключении.

## Нерешённые вопросы

- Версионирование набора инструментов (клиент кэширует список?).
