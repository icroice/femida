# 006 — UI-каркас v2

## Цель

Общая оболочка приложения: шапка с навигацией модулей, тёмная левая панель,
переключатель проектов. Эталон — стайлгайд `/styleguide`.

## Контекст

Спека §9, секция «Каркас» стайлгайда. Существующие страницы v1 втекают в
новый каркас без переделки своего содержимого.

## Критерии готовности

- Шапка h-14 sticky: логотип, табы модулей (только предоставленные ∧
  включённые ∧ с правом `view` у роли), переключатель проектов, профиль
  с меню.
- Тёмная левая панель `.app-sidebar` (класс, не тег): разделы активного
  модуля, счётчики, локальные токены панели.
- Активный пункт навигации — `aria-current="page"`, вид задаёт CSS
  (фирменный градиент), классов подсветки в разметке нет.
- Дропдауны на focus/tabindex без JS; иконки lucide (`data-lucide`).
- Страницы v1 открываются в новом каркасе, ничего не потеряно.
- Мобильная деградация: панель скрывается, шапка сворачивается.
