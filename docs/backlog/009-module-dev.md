# 009 — Модуль `dev`

## Цель

Стадия разработки: связь задачи с веткой и pull request, статусы работы.

## Контекст

Спека §3. Задача приходит из `spec` (008), уходит в `review` (010).

## Критерии готовности

- Дескриптор модуля: секция разработки, роли, колонка «Разработка».
- В задаче — поля «ветка» и «pull request» (ссылки, валидация формата).
- Статусы внутри стадии: не начата / в работе / на паузе (виден в колонке).
- Перевод в ревью фиксируется в истории задачи.
- Права через AccessService.

## Смежные задачи

Статусы PR с git-хостинга (v2-9) — задача 015.

## Нерешённые вопросы

  конвенция имён веток.
