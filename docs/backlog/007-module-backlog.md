# 007 — Модуль `backlog`

## Цель

Первая стадия жизненного цикла: пул задач проекта, приоритеты, создание.

## Контекст

Спека §3. Колонка «Бэклог» на доске (002), сущность задачи — 005.
Первый модуль, собранный на движке 001/004: его дескриптор — образцовый.

## Критерии готовности

- Дескриптор: секция задач с правами, бизнес-роли модуля, колонка «Бэклог».
- Создание и редактирование задач из доски и страницы списка.
- Приоритизация: порядок в пуле меняется (drag в колонке), приоритет виден.
- Перевод задачи в стадию проработки (колонка модуля `spec`).
- Доступ — только через AccessService; роли модуля назначаются владельцем.
- Пустое состояние пула и фильтры — по стайлгайду.

## Нерешённые вопросы

- Шкала приоритета: порядок против явных категорий (высокий/средний/низкий).
- Импорт задач (CSV/из трекера) — в этом модуле или отдельной задачей.
