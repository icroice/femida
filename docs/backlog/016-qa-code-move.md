# 016 — Перенос кода v1 в структуру модуля `qa`

## Цель

Физический переезд: контроллеры, модели, вьюхи, маршруты и тесты v1 из
ядра в структуру модуля `qa`. Поведение не меняется — меняется адрес кода.

## Контекст

После 011 v1 уже привязан к модулю логически; здесь наводим порядок в
дереве кода. Спека §4.

## Критерии готовности

- Структура модуля принята как образцовая для будущих модулей
  (маршруты/контроллеры/вьюхи/миграции внутри пространства модуля).
- Весь код QA-функциональности живёт в структуре модуля; в ядре — только
  платформенное.
- Тесты v1 зелёные (правки только путей классов/неймспейсов).
- REST API v1 и MCP работают без изменения контрактов.

## Нерешённые вопросы

- Каталог модулей: `app/Modules/Qa`, `routes/modules/qa.php` — точную
  схему принять здесь и зафиксировать в спеке.
