# 014 — Доска: drag-and-drop, фильтры, счётчики

## Цель

Доска из 002 становится рабочим инструментом: перенос карт мышью, фильтры,
счётчики.

## Контекст

Продолжение 002. Переходы уже есть (меню карточки, история пишется).

## Критерии готовности

- Drag-and-drop карточки между колонками: тот же переход, что из меню —
  одна кодовая дорожка, история не расходится.
- Недоступный переход (нет права) — карточка возвращается, всплывает
  причина.
- Фильтры: по исполнителю, по модулю; счётчики в заголовках колонок.
- Мобильная версия: drag-and-drop деградирует в кнопки-переходы из меню.

## Нерешённые вопросы

- Библиотека dnd: нативный HTML5 DnD против лёгкой зависимости.
